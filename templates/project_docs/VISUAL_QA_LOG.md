## Review checklist
- [ ] Reference image and app screenshot use comparable viewport dimensions and scale.
- [ ] Evidence records device/emulator, OS version, text scale, theme and locale.
- [ ] Safe areas and system bars.
- [ ] Typography, line wrapping, enlarged text and overflow.
- [ ] Spacing, alignment, colors, borders, elevation and icons.
- [ ] Scroll behavior, keyboard and Android back behavior.
- [ ] Loading, empty, error, offline and permission states where relevant.
- [ ] Tap targets, focus order, semantics and contrast.
- [ ] Motion and reduced-motion behavior where applicable.
- [ ] Differences are reviewed manually; dynamic content and anti-aliasing are considered.

A mockup is not evidence that a Flutter screen runs. Store runtime screenshots and test/device context where available. Use `NOT RUN` until actual evidence is captured.
