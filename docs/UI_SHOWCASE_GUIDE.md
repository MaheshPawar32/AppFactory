# UI showcase guide

The Nova UI showcase should act as a live catalog for existing shared components.

For each component, document:
- Name and intended use.
- Supported variants and parameters.
- Light/dark theme behavior.
- Loading, disabled, error and empty states where applicable.
- Accessibility semantics and touch-target behavior.
- A small usage example.
- Widget tests.

Suggested showcase categories:
- Foundations: colors, typography, spacing, radii and motion.
- Actions: buttons, icon buttons and links.
- Inputs: text fields, validation and selection controls.
- Feedback: banners, snackbars, dialogs and bottom sheets.
- Data display: cards, list tiles, badges and charts when needed.
- Navigation: app bars, bottom navigation and responsive patterns.
- States: skeletons, loading, empty, error and offline.
- Layout: compact/medium/expanded examples.

Do not mark a component complete until the example and tests exist or the gap is clearly documented.
