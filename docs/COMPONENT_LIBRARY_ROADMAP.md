# Component library roadmap

Before adding a component, check whether Nova UI already has a matching implementation. Keep the library small, documented and tested.

## Suggested next components
- Confirmation dialog and bottom sheet patterns.
- Search field and filter chips.
- Date/time field wrappers.
- Empty-state and retry action patterns.
- Pagination and infinite-list guidance.
- Image picker/media preview patterns.
- Responsive navigation shell examples.
- Chart wrappers only when a concrete app needs them.

## Component acceptance criteria
- Consistent Nova UI tokens and theme behavior.
- Accessible semantics and appropriate touch targets.
- Loading/disabled/error states where relevant.
- A showcase example.
- Focused widget tests.
- Documentation for parameters and usage.
